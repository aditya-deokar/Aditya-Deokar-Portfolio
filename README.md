## 📖 About the Project

This is my personal portfolio website — built with a **sleek black & white aesthetic** to let the work speak for itself. It's crafted to give visitors a seamless experience while exploring my skills, projects, education, and ways to get in touch.

Every animation, transition, and layout detail has been carefully designed to reflect my approach to frontend development: **clean, performant, and visually compelling**.

## 🚀 Getting Started

No build tools or package managers required — just open it in your browser!

```bash
# 1. Clone the repository
git clone https://github.com/aditya-deokar/Aditya-Deokar-Portfolio.git

# 2. Navigate into the project folder
cd Aditya-Deokar-Portfolio

# 3. Open in browser
open index.html
```

Or simply visit the **[live site →](https://aditya-deokar.github.io/Aditya-Deokar-Portfolio/)**
